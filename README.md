# DIAMOND APPAREL OS

Owner-only autonomous iPhone app for DIAMOND APPAREL.

## Setup
1. `npm install`
2. Add `.env` with EXPO_PUBLIC_OPENAI_KEY, EXPO_PUBLIC_SUPABASE_URL, EXPO_PUBLIC_SUPABASE_ANON_KEY
3. `npx expo start --ios`

Run `runFullDrop(theme)` from create screen to trigger full AI pipeline.
